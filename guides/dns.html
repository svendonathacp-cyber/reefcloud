🧭 DNS umbiegen

Damit Handy und Geräte deinen Pi statt der toten Hersteller-Cloud finden.

Was bedeutet das?

Immer wenn die App oder deine Geräte etwas von der Cloud wollen, fragen sie zuerst: „Wo ist api.reeffactory.com?" Bisher hat das Internet geantwortet — jetzt soll dein eigenes Netzwerk antworten: „Die ist bei deinem Pi zu Hause!" Dieses Umleiten nennt man DNS-Umschreibung. Du trägst dafür einmalig die Adresse und die IP deines Pi ein — wie einen Hinweiszettel am schwarzen Brett deines Heimnetzes.

1 · Trage zuerst die IP deines Pi ein

Die IP-Adresse deines reef-cloud-Servers steht in der Setup-Seite bzw. im Dashboard (z. B. unter „LAN-IP"). Tippe sie hier ein — sie wird automatisch in allen Beispielen unten eingesetzt und auf diesem Gerät gespeichert.

Die IP bleibt nur in diesem Browser gespeichert (localStorage), nichts wird versendet.

2 · Wähle deinen Weg

Je nachdem, was bei dir zu Hause läuft — ein Weg genügt:

empfohlen Weg A · AdGuard Home
  1. Öffne die AdGuard-Home-Weboberfläche (im Browser, meist Port 80 oder 3000).
  2. Gehe oben im Menü auf Filter → DNS-Umschreibungen.
  3. Klicke auf „Umschreibung hinzufügen".
  4. Trage ein:
    · Domain: api.reeffactory.com
    · IP-Adresse: ‹Pi-IP›
  5. Speichern — fertig.
alternativ Weg B · Pi-hole
  1. Öffne die Pi-hole-Weboberfläche im Browser.
  2. Gehe links im Menü auf Local DNS → DNS Records (ältere Versionen: „Local DNS Records").
  3. Trage ein:
    · Domain: api.reeffactory.com
    · IP Address: ‹Pi-IP›
  4. Klicke auf „Add" — der Eintrag erscheint in der Liste darunter.
nur mit Helfer Weg C · Fritz!Box

Ehrlich gesagt: Eine Fritz!Box kann selbst keine DNS-Umschreibungen für einzelne Adressen — diese Funktion hat AVM nicht eingebaut. Aber es gibt eine einfache Lösung: Die Fritz!Box soll als DNS-Server dein AdGuard Home oder deinen Pi-hole verwenden (auf dem du dann Weg A oder B einrichtest).

  1. Richte zuerst Weg A (AdGuard) oder Weg B (Pi-hole) ein — dort passiert die eigentliche Umschreibung.
  2. Öffne fritz.box im Browser und melde dich an.
  3. Gehe zu Heimnetz → Netzwerk → Netzwerkeinstellungen.
  4. Scrolle zu „DNS-Server" bzw. „Lokaler DNS-Server" und trage dort die IP deines AdGuard-/Pi-hole-Geräts ein (wenn AdGuard/Pi-hole auf demselben Pi laufen: ‹Pi-IP›).
  5. Speichern. Die Fritz!Box verteilt diese DNS-Adresse ab jetzt an alle Geräte im WLAN.
⚠️ Falls du weder AdGuard Home noch Pi-hole hast: Installiere eins davon zuerst (beides läuft gut auf demselben Raspberry Pi). Danach Weg A oder B folgen.

🧪 Fertig-Test: Klappt alles?

Ein Knopfdruck prüft zwei Dinge von diesem Gerät aus:

  • Test 1 (DNS): Antwortet http://api.reeffactory.com? Dann zeigt die Adresse auf deinen Pi — die Umschreibung funktioniert.
  • Test 2 (Zertifikat): Antwortet auch https://api.reeffactory.com? Das gelingt nur, wenn zusätzlich das Zertifikat aus Schritt 1 installiert ist. Schlägt Test 2 fehl, fehlt meist nur noch das Zertifikat auf diesem Gerät.

🎉 Alles eingerichtet! DNS zeigt auf deinen Pi und das Zertifikat wird vertraut. Öffne jetzt die Reef-Factory-App — deine Geräte sollten wieder erreichbar sein.

Hinweis: Öffne diese Anleitung am besten über http://-Adresse deines Pi (z. B. http://‹Pi-IP›/guides/) — sonst kann der Browser den unverschlüsselten Test 1 blockieren.
